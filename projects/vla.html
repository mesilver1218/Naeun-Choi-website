Deploying and evaluating LightNav-0 for VLA-based human following on a real quadruped robot.
RGB observation→LightNav-0→Robot motion→Real-world evaluation

Overview

Following the development of my modular human-following system on Unitree Go2, I deployed the pre-trained LightNav-0 Vision–Language–Action (VLA) model to evaluate person-following behaviors on a physical quadruped. The objective was to investigate practical model deployment, not to train a new navigation policy.

I reused the lower-level infrastructure established during modular human following: LiDAR SLAM, ROS 2 navigation, path execution, and the final Unitree Go2 motion-control interface. LightNav-0 took over the vision-conditioned target-following and local action-planning functions, while the existing robotics stack continued to execute paths and velocity commands.

Integrating a learned VLA planner with a proven physical-robot navigation stack.

Method & Implementation

  • LightNav-0 and Waypoint ExecutionIntegrated LightNav-0 to generate 10 robot-relative waypoints from visual observations and target instructions; transformed the predicted path through TF for Nav2 FollowPath execution.
  • Reusing the Modular Navigation StackRetained LiDAR-based SLAM, Nav2 path tracking, and the Unitree Go2 SDK motion interface from the modular human-following system.
  • Onboard Real-Time InferenceRan LightNav-0 on Jetson AGX Thor at approximately 2 Hz, with Jetson Orin NX handling navigation and robot communication.

Validation & Context

LightNav-0 was deployed and evaluated on a physical Unitree Go2 in indoor person-following scenarios. This page describes the system integration and evaluation workflow without asserting an unpublished numerical performance improvement.

Due to internal policy, the source code cannot be publicly released.

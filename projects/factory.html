Making six sensor–actuator systems work reliably together on a microcontroller.
Sensor readings→Timer / interrupt logic→PWM + state rules→Coordinated actions

Overview

This embedded-systems team project aimed to integrate multiple independent sensor and actuator functions into a single functioning smart-factory prototype on an ATmega128 microcontroller. The main difficulty was ensuring that every subsystem could operate reliably in combination, rather than only working in isolation.

The finished system combined environmental and proximity sensing, automated responses, and user-facing indicators, creating a small example of real-time embedded integration and fault isolation.

System-level reliability from interrupt timing and coordinated sensor–actuator behavior.

Method & Implementation

  • Sensor–Actuator IntegrationCoordinated six factory functions, including conveyor motion, automated curtains, environmental sensing, alerts, and status displays on ATmega128.
  • Embedded PeripheralsUsed ADC, PWM, USART, timers, and interrupt-based control to connect multiple sensors and actuators.
  • System-Level DebuggingResolved integrated-system freezes caused by conflicting timer/interrupt settings, including an unnecessary Timer 3 interrupt enable.

Validation & Context

Demonstrated six coordinated sensor–actuator subsystems on a physical smart-factory prototype. The project illustrated that integrating independently working embedded modules requires managing shared clocks, timers, interrupts, and state transitions across the entire system.

My documented work included ATmega128 software integration, peripheral configuration, and system-level troubleshooting.
